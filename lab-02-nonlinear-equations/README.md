## 1. Метод половинного деления

**Дано**

$$
f(x)=-\ln x+0.2x^2-1,\qquad [a,b]=[2,4].
$$

**Решение**

Проверяем значения на концах:

$$
f(2)\approx-0.893147,\qquad f(4)\approx0.813706.
$$

Функция непрерывна на $[2,4]$, произведение значений отрицательное. На отрезке имеется корень. Делим отрезок пополам, выбирая часть, на концах которой знаки функции различаются.

$$
c=\frac{a+b}{2}.
$$

| Отрезок до шага | Середина $c$ | $f(c)$ | Отрезок после шага |
| --- | ---: | ---: | --- |
| $[2;4]$ | 3 | $-0.298612$ | $[3;4]$ |
| $[3;4]$ | 3.5 | $0.197237$ | $[3;3.5]$ |
| $[3;3.5]$ | 3.25 | $-0.066155$ | $[3.25;3.5]$ |

Этим действиям соответствует часть `bisection()`:

```python
middle = (left + right) / 2.0  # Середина отрезка
value = equation(middle)       # Значение функции в середине

if left_value * value < 0.0:
    right = middle             # Смена знака на левой половине
else:
    left = middle              # Смена знака на правой половине
    left_value = value
```

`left_value` содержит $f(left)$; после изменения левой границы значение функции обновляется. Длина отрезка сокращается вдвое на каждом шаге.

Невязка в текущей точке равна $|f(c)|$. Поскольку корень находится внутри отрезка, абсолютная погрешность середины не превышает половины длины отрезка:

$$
|c-x_*|\leq\frac{b-a}{2}.
$$

Код оценки погрешности и остановки:

```python
error = (right - left) / 2.0
history.append([iteration, middle, abs(value), error])

if error <= eps / 2.0:
    return middle, history
```

`history` хранит номер шага, приближение, невязку и оценку погрешности. Если значение функции на конце или в середине равно нулю, корень найден точно в машинной арифметике.

**Ответ** $x\approx3.31559798$; 28 делений между начальным отрезком и последним приближением, которое имеет номер 28 при нумерации с нуля (29 записей в `history`).

## 2. Метод Ньютона–Рафсона

**Дано**

$$
f(x)=-\ln x+0.2x^2-1,\qquad x\in[2;4],\qquad x_0=4.
$$

**Решение**

В текущей точке $x_k$ проводим касательную. Её наклон равен $f'(x_k)$, высота точки графика — $f(x_k)$. Пересечение касательной с осью абсцисс даёт новое приближение.

Уравнение касательной:

$$
y=f(x_k)+f'(x_k)(x-x_k).
$$

При $y=0$ получаем формулу:

$$
x_{k+1}=x_k-\frac{f(x_k)}{f'(x_k)}.
$$

Для нашей функции

$$
f'(x)=-\frac1x+0.4x,\qquad f''(x)=\frac1{x^2}+0.4>0.
$$

На отрезке $[2,4]$ первая производная положительна, вторая также положительна. При $x_0=4$ выполняется $f(4)f''(4)>0$. Это достаточное условие выбора начальной точки по теореме из учебника при остальных выполненных предпосылках.

Первая итерация:

$$
f(4)\approx0.813705639,\qquad f'(4)=1.35,
$$

$$
x_1=4-\frac{0.813705639}{1.35}\approx3.397255082.
$$

Вторая итерация:

$$
f(x_1)\approx0.085300642,\qquad f'(x_1)\approx1.064546744,
$$

$$
x_2=x_1-\frac{f(x_1)}{f'(x_1)}\approx3.317126481.
$$

В `newton()` на каждом шаге выполняются:

```python
value = equation(x)      # Значение функции
slope = derivative(x)    # Наклон касательной, f'(x)
x = x - value / slope   # Пересечение касательной с осью x
```

`derivative(x)` вычисляет заранее полученную аналитическую формулу производной при текущем `x`. Производная пересчитывается после изменения приближения. Перед делением программа проверяет, что `slope` не слишком мал.

Для оценки погрешности используем $m=\min_{[2,4]}|f'(x)|=f'(2)=0.3$:

$$
|x_k-x_*|\leq\frac{|f(x_k)|}{m}.
$$

```python
minimum_derivative = derivative(LEFT)  # 0.3
error = abs(value) / minimum_derivative
history.append([iteration, x, abs(value), error])

if error <= eps / 2.0:
    return x, history
```

**Ответ** $x\approx3.31559798$. Выполнено 4 перехода к новому приближению; последняя невязка $\approx7.73\cdot10^{-14}$.

## 3. Метод секущих (хорд)

**Дано**

$$
f(x)=-\ln x+0.2x^2-1,\qquad x_0=2,\quad b=4.
$$

**Решение**

Через точки графика $(x_k,f(x_k))$ и $(b,f(b))$ проводим хорду. Её пересечение с осью абсцисс принимаем за следующее приближение. В этой реализации правый конец $b$ остаётся неподвижным.

Наклон хорды:

$$
m=\frac{f(b)-f(x_k)}{b-x_k}.
$$

При пересечении прямой с осью $y=0$, поэтому

$$
x_{k+1}=x_k-\frac{f(x_k)}{m}
=x_k-\frac{f(x_k)(b-x_k)}{f(b)-f(x_k)}.
$$

На первом шаге $f(2)\approx-0.893147$, $f(4)\approx0.813706$:

$$
x_1=2-\frac{-0.893147(4-2)}{0.813706-(-0.893147)}
\approx3.046543.
$$

На следующем шаге точку $x=2$ заменяем на $x_1$; $b=4$ остаётся прежним:

$$
f(x_1)\approx-0.257723,
$$

$$
x_2=x_1-\frac{f(x_1)(4-x_1)}{f(4)-f(x_1)}
\approx3.275889.
$$

В коде `chords()`:

```python
x = left
right_value = equation(right)  # Значение функции в фиксированной точке

# Внутри цикла
value = equation(x)
denominator = right_value - value
x = x - value * (right - x) / denominator
```

`denominator` — разность высот концов хорды. При изменении `x` меняется наклон прямой и её пересечение с осью. Для возрастающей выпуклой функции варианта 11 приближения идут слева от корня.

Производная не участвует в вычислении нового приближения. В программе она нужна для оценки погрешности, как в методе Ньютона:

```python
minimum_derivative = derivative(LEFT)
error = abs(value) / minimum_derivative
```

Перед вычислением очередного `x` код проверяет, что `denominator` не слишком мал.

**Ответ** $x\approx3.31559798$, 11 переходов, невязка $\approx7.56\cdot10^{-10}$.

## 4. Комбинированный метод

**Дано**

$$
f(x)=-\ln x+0.2x^2-1,\qquad [a_0,b_0]=[2,4].
$$

**Решение**

Корень уточняется с двух сторон. Левый конец перемещаем методом хорд, правый — методом Ньютона. Для вычисления обеих новых границ берём значения предыдущего шага:

$$
a_{k+1}=a_k-\frac{f(a_k)(b_k-a_k)}{f(b_k)-f(a_k)},
$$

$$
b_{k+1}=b_k-\frac{f(b_k)}{f'(b_k)}.
$$

Первый проход при $a_0=2$, $b_0=4$:

$$
a_1\approx3.046542702,\qquad b_1\approx3.397255082.
$$

Теперь корень заключён в отрезке $[3.046542702;3.397255082]$. Следующий проход даёт

$$
a_2\approx3.310042440,\qquad b_2\approx3.317126481.
$$

Фрагмент `combined()`:

```python
left_value = equation(left)
right_value = equation(right)
denominator = right_value - left_value
slope = derivative(right)

new_left = left - left_value * (right - left) / denominator
new_right = right - right_value / slope
left = new_left
right = new_right
```

`new_left` и `new_right` вычисляются отдельно, чтобы оба выражения использовали старые границы. При $f'>0$, $f''>0$ и смене знака на концах новый отрезок сохраняет корень.

В качестве приближения берём его середину:

```python
middle = (left + right) / 2.0
value = equation(middle)
error = (right - left) / 2.0
history.append([iteration, middle, abs(value), error])
```

Точность контролируется по половине длины текущего отрезка. В программе `middle` и `error` записываются до очередного обновления границ.

**Ответ** $x\approx3.31559798$. Четыре прохода уточнения границ; невязка $\approx1.02\cdot10^{-13}$.

## 5. Метод простых итераций

**Дано**

$$
f(x)=-\ln x+0.2x^2-1=0,\qquad x_0=2.
$$

**Решение**

Преобразуем уравнение $f(x)=0$ к виду $x=\varphi(x)$:

$$
0.2x^2=\ln x+1,
$$

$$
\boxed{\varphi(x)=\sqrt{5(\ln x+1)}}.
$$

Положительную ветвь корня выбираем потому, что $x\in[2;4]$.

Каждое новое приближение получается подстановкой предыдущего:

$$
x_{k+1}=\varphi(x_k).
$$

Для первых шагов:

$$
x_1=\varphi(2)\approx2.909593769,
$$

$$
x_2=\varphi(x_1)\approx3.215597513,
$$

$$
x_3=\varphi(x_2)\approx3.292425544.
$$

Код `simple_iterations()`:

```python
next_x = iteration_function(x)
error = q * abs(next_x - x) / (1.0 - q)
x = next_x
```

Здесь `iteration_function()` вычисляет $\varphi(x)$, а `q` используется для оценки погрешности.

Проверяем достаточные условия сходимости. Производная функции итерации:

$$
\varphi'(x)=\frac{5}{2x\sqrt{5(\ln x+1)}}.
$$

На $[2;4]$ производная положительна и убывает, поэтому

$$
q=\max_{[2,4]}|\varphi'(x)|=\varphi'(2)\approx0.42961324<1.
$$

Также

$$
\varphi([2;4])\approx[2.90959377;3.45419626]\subset[2;4].
$$

Следовательно, функция итерации отображает отрезок в себя и является сжимающей. После шага для нового приближения используется оценка:

$$
|x_{k+1}-x_*|\leq\frac{q}{1-q}|x_{k+1}-x_k|.
$$

В нулевой записи `history` применяется оценка $|f(x_0)|/0.3$, поскольку пары последовательных приближений ещё нет.

**Ответ** $x\approx3.31559798$, 15 переходов, невязка $\approx4.57\cdot10^{-10}$.

## 6. Метод Ньютона для системы

**Дано**

Учебный пример с простой системой:

$$
\begin{cases}
F_1(x,y)=x^2+y-5=0,\\
F_2(x,y)=x+y^2-3=0,
\end{cases}
\qquad (x_0,y_0)=(1.5,0.5).
$$

В проекте функция `system_values()` вычисляет систему варианта 11, указанную в начале README. Алгоритм решения одинаков.

**Решение**

На каждой итерации вычисляем две поправки $\Delta x$, $\Delta y$. Линеаризация около текущей точки:

$$
F(x+\Delta x,y+\Delta y)\approx F(x,y)+J(x,y)
\begin{pmatrix}\Delta x\\\Delta y\end{pmatrix}.
$$

Матрица Якоби для примера:

$$
J(x,y)=
\begin{pmatrix}
2x&1\\
1&2y
\end{pmatrix}.
$$

Приравниваем линейное приближение к нулю и решаем систему:

$$
J(x,y)
\begin{pmatrix}\Delta x\\\Delta y\end{pmatrix}
=-\begin{pmatrix}F_1(x,y)\\F_2(x,y)\end{pmatrix}.
$$

В точке $(1.5,0.5)$:

$$
F_1=-2.25,\quad F_2=-1.25,\qquad
J=\begin{pmatrix}3&1\\1&1\end{pmatrix}.
$$

Получаем СЛАУ для поправок:

$$
\begin{cases}
3\Delta x+\Delta y=2.25,\\
\Delta x+\Delta y=1.25.
\end{cases}
$$

Вычитаем второе уравнение из первого: $2\Delta x=1$, откуда $\Delta x=0.5$, $\Delta y=0.75$. Следующее приближение $(x_1,y_1)=(2,1.25)$.

В `newton_system()` система 2×2 для поправок решается по формулам Крамера:

```python
matrix = jacobian(x, y)
j11 = matrix[0][0]
j12 = matrix[0][1]
j21 = matrix[1][0]
j22 = matrix[1][1]
determinant = j11 * j22 - j12 * j21

delta_x = (-first * j22 + j12 * second) / determinant
delta_y = (j21 * first - j11 * second) / determinant
x = x + delta_x
y = y + delta_y
```

`first` и `second` содержат значения $F_1$ и $F_2$, `j11`–`j22` — элементы матрицы Якоби. Перед делением проверяется модуль определителя. На следующей итерации функции и матрица Якоби вычисляются снова.

Для реальной системы варианта 11:

$$
J(x,y)=
\begin{pmatrix}
-\cos(-x+\pi/2+2)&1\\
-1&\sin(-y+\pi/2-0.5)
\end{pmatrix}.
$$

Условие остановки в программе:

$$
r=\max(|F_1(x,y)|,|F_2(x,y)|)\leq\varepsilon/2.
$$

**Ответ для учебного примера** $(x,y)=(2,1)$; оба уравнения выполняются при подстановке. **Ответ варианта 11** $(x,y)\approx(-0.13868462;0.53785300)$.

## 7. Метод спуска

**Дано**

Используем учебную систему из задания 6:

$$
F_1(x,y)=x^2+y-5,\qquad F_2(x,y)=x+y^2-3,
$$

$$
(x_0,y_0)=(1.5,0.5).
$$

В проекте метод `gradient_descent()` применяется к системе варианта 11, старт $(-1,0)$.

**Решение**

Составляем сумму квадратов невязок:

$$
\Psi(x,y)=F_1(x,y)^2+F_2(x,y)^2.
$$

Если $\Psi=0$, оба исходных уравнения выполнены. Градиент этой функции:

$$
\begin{aligned}
\Psi_x&=2(F_1F_{1x}+F_2F_{2x}),\\
\Psi_y&=2(F_1F_{1y}+F_2F_{2y}).
\end{aligned}
$$

Он направлен в сторону наибольшего локального роста. Для уменьшения $\Psi$ используем антиградиент:

$$
x_{k+1}=x_k-\alpha\Psi_x,\qquad
 y_{k+1}=y_k-\alpha\Psi_y.
$$

Для учебной системы в начальной точке:

$$
F_1=-2.25,\quad F_2=-1.25,\quad \Psi=6.625,
$$

$$
\Psi_x=4xF_1+2F_2=-16,\qquad
\Psi_y=2F_1+4yF_2=-7.
$$

Начинаем с пробного шага $\alpha=0.25$. Если новая сумма квадратов больше исходной, уменьшаем шаг вдвое.

| Шаг $\alpha$ | Новая точка $(x-\alpha\Psi_x,\,y-\alpha\Psi_y)$ | Новая $\Psi$ | Результат |
| ---: | --- | ---: | --- |
| 0.25 | $(5.5;2.25)$ | 813.44140625 | Отклоняем |
| 0.125 | $(3.5;1.375)$ | 80.10571289 | Отклоняем |
| 0.0625 | $(2.5;0.9375)$ | 4.92872620 | Принимаем |

В `gradient_descent()`:

```python
first, second = system_values(x, y)
psi = first * first + second * second
matrix = jacobian(x, y)
grad_x = 2.0 * (first * matrix[0][0] + second * matrix[1][0])
grad_y = 2.0 * (first * matrix[0][1] + second * matrix[1][1])

step = DESCENT_STEP
while True:
    next_x = x - step * grad_x
    next_y = y - step * grad_y
    next_first, next_second = system_values(next_x, next_y)
    next_psi = next_first * next_first + next_second * next_second
    if next_psi < psi:
        break
    step = step / 2.0

x = next_x
y = next_y
```

В реальном коде дополнительно проверяются нулевой градиент и минимальный допустимый шаг. Пока выбирается `step`, текущие `x` и `y` не изменяются. Новую точку принимаем только после уменьшения $\Psi$.

В этой реализации остановка требует малой невязки $\max(|F_1|,|F_2|)$; стационарная точка с $\Psi>0$ не считается решением системы. Выбор шага дроблением — приближённый поиск подходящего шага, без точной минимизации вдоль направления.

**Ответ для учебного примера** $(x,y)\approx(2,1)$. **Ответ варианта 11** $(x,y)\approx(-0.13868462;0.53785300)$.

## 8. Сравнение результатов

**Дано**

Результаты заданий 1–7 для варианта 11, при $\varepsilon=10^{-8}$.

**Решение**

Для скалярного уравнения невязка $r=|f(x)|$. Для системы используем

$$
r=\max(|F_1(x,y)|,|F_2(x,y)|).
$$

Погрешность — отличие найденного решения от точного. Программа не знает точный корень; для методов 1–5 используются оценки погрешности:

| Метод | Оценка |
| --- | --- |
| Половинное деление | $(b-a)/2$ |
| Ньютон, хорды | $|f(x)|/0.3$ |
| Комбинированный | $(b-a)/2$ |
| Простые итерации | $\frac{q}{1-q}|x_k-x_{k-1}|$ после первого шага |

В `src/output.py` метод `print_comparison()` выводит приближения, невязки и число итераций. Для системы код вычисляет невязку так:

```python
first, second = system_values(x, y)
residual = max(abs(first), abs(second))
```
