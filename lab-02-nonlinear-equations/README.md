## Условия для скалярных методов

На отрезке $[2,4]$ функция непрерывна,

$$
f(2)\approx-0.89314718,\qquad f(4)\approx0.81370564.
$$

Производные

$$
f'(x)=-\frac1x+0.4x,\qquad f''(x)=\frac1{x^2}+0.4>0.
$$

Производная $f'$ возрастает и положительна. Поэтому корень на отрезке единственный, а $m=\min f'(x)=f'(2)=0.3$. По теореме о среднем

$$
|x-x_*|\leq\frac{|f(x)|}{m},\qquad x\in[2,4].
$$

Эта оценка используется в методах Ньютона и хорд. Для Ньютона начальное значение $x_0=4$ удовлетворяет достаточному условию $f(x_0)f''(x_0)>0$. В методе хорд правая точка 4 остаётся неподвижной. Это схема из § 3.4 пособия.

Ниже даны отдельные небольшие примеры для разбора вычислений. Исходники проекта решают фиксированный вариант 11. В примерах функции заменены более простыми; операции обновления приближений остаются теми же.

## 1. Половинное деление

**Дано**

$$
f(x)=x^2-2,\qquad [a,b]=[1,2].
$$

**Решение**

При непрерывной функции смена знака на концах гарантирует наличие корня. Берём середину отрезка и оставляем половину со сменой знака.

$$
c=(a+b)/2.
$$

| Отрезок до шага | Середина | Значение функции | Новый отрезок |
| --- | ---: | ---: | --- |
| $[1,2]$ | 1.5 | 0.25 | $[1,1.5]$ |
| $[1,1.5]$ | 1.25 | -0.4375 | $[1.25,1.5]$ |
| $[1.25,1.5]$ | 1.375 | -0.109375 | $[1.375,1.5]$ |

В `bisection()` эти действия записаны так

```python
middle = (left + right) / 2.0
value = equation(middle)

if left_value * value < 0.0:
    right = middle
else:
    left = middle
    left_value = value
```

`left_value` хранит значение функции на текущем левом конце. Если произведение отрицательно, корень сохраняется между `left` и `middle`. Иначе заменяется левый конец вместе со значением функции в нём.

Для середины текущего отрезка оценка ошибки равна $(b-a)/2$. В программе именно длина отрезка определяет остановку. После каждого деления отрезок становится вдвое короче.

**Ответ** $x=\sqrt2\approx1.41421356$.

## 2. Метод Ньютона–Рафсона

**Дано**

$$
f(x)=x^2-2,\qquad f'(x)=2x,\qquad x_0=2.
$$

**Решение**

Касательная в точке $x_k$ имеет уравнение $t=f(x_k)+f'(x_k)(x-x_k)$. При $t=0$ получаем следующее приближение

$$
x_{k+1}=x_k-\frac{f(x_k)}{f'(x_k)}.
$$

$$
x_1=2-\frac{2}{4}=1.5,\qquad
x_2=1.5-\frac{0.25}{3}=1.41666667.
$$

Фрагмент `newton()`

```python
value = equation(x)
slope = derivative(x)
x = x - value / slope
```

`value` — высота графика над осью, `slope` — наклон касательной. Их отношение даёт поправку к аргументу. На следующем проходе обе величины пересчитываются в новой точке.

Для функции примера на $[1,2]$ можно взять $m=2$ и оценивать ошибку через $|x^2-2|/2$. Для варианта 11 в коде используется $m=0.3$. Ненулевая производная необходима для деления; начальная точка и свойства функции определяют сходимость.

**Ответ** $x=\sqrt2\approx1.41421356$.

## 3. Метод секущих, неподвижный конец

**Дано**

$$
f(x)=x^2-2,\qquad x_0=1,\qquad b=2.
$$

**Решение**

Через $(x_k,f(x_k))$ и $(b,f(b))$ проводим прямую. Её пересечение с осью даёт новое $x$. Правая точка $b$ не изменяется.

$$
x_{k+1}=x_k-\frac{f(x_k)(b-x_k)}{f(b)-f(x_k)}.
$$

$$
x_1=1-\frac{(-1)(2-1)}{2-(-1)}=\frac43,
$$

$$
f(4/3)=-2/9,\qquad
x_2=\frac43-\frac{(-2/9)(2-4/3)}{2+2/9}=1.4.
$$

Фрагмент `chords()`

```python
value = equation(x)
denominator = right_value - value
x = x - value * (right - x) / denominator
```

`right` и `right_value` сохраняют неподвижную точку и значение функции в ней. `denominator` означает знаменатель. Малый знаменатель проверяется перед делением.

Для заданной возрастающей выпуклой функции приближения идут слева к корню. Проверка остановки использует $|f(x)|/m$. Производная в формулу хорд не входит; в этой программе её нижняя граница нужна для оценки погрешности.

**Ответ** $x=\sqrt2\approx1.41421356$.

## 4. Комбинированный метод

**Дано**

$$
f(x)=x^2-2,\qquad [a_0,b_0]=[1,2].
$$

**Решение**

Левая граница обновляется по хорде, правая — по касательной. Обе формулы используют границы предыдущего шага.

$$
a_{k+1}=a_k-\frac{f(a_k)(b_k-a_k)}{f(b_k)-f(a_k)},\qquad
b_{k+1}=b_k-\frac{f(b_k)}{f'(b_k)}.
$$

На первом шаге

$$
a_1=\frac43,\qquad b_1=\frac32.
$$

Корень находится внутри $[4/3,3/2]$. Его приближение — середина $17/12$, оценка ошибки — половина длины отрезка, $1/12$.

Следующий шаг даёт $a_2=24/17$, $b_2=17/12$.

Фрагмент `combined()`

```python
new_left = left - left_value * (right - left) / denominator
new_right = right - right_value / slope
left = new_left
right = new_right
```

Здесь `denominator = right_value - left_value`, `slope = derivative(right)`. Новые границы сначала записываются в отдельные переменные. Обновление `left` не должно менять исходные данные того же шага.

Возвращается середина последнего отрезка. Условия $f'>0$, $f''>0$, $f(a)<0<f(b)$ обеспечивают сохранение корня между границами; они выполнены и в примере, и в варианте 11.

**Ответ** $x=\sqrt2\approx1.41421356$.

## 5. Простые итерации

**Дано (вариант 11)**

$$
f(x)=-\\ln x+0.2x^2-1=0,\\qquad x\\in[2,4].
$$

**Приводим к виду $x=\\varphi(x)$**

$$
0.2x^2=\\ln x+1\\quad\\Longrightarrow\\quad
x=\\varphi(x)=\\sqrt{5(\\ln x+1)}.
$$

На каждой итерации подставляем предыдущее приближение в одну и ту же формулу:

$$
x_{k+1}=\\sqrt{5(\\ln x_k+1)},\\qquad x_0=3.
$$

В `src/data.py` функция `iteration_function(x)` возвращает правую часть этой формулы. В `src/scalar_methods.py` функция `simple_iterations()` выполняет её в цикле:

```python
x_next = iteration_function(x)
difference = abs(x_next - x)
error = q * difference / (1.0 - q)
residual = abs(equation(x_next))
```

Здесь `difference` — изменение приближения, `error` — гарантированная верхняя оценка ошибки по теореме §3.6, `residual` — невязка исходного уравнения. При продолжении цикла `x = x_next`, а при выполнении порога метод возвращает найденное значение и историю.

**Проверяем сходимость**

$$
\\varphi'(x)=\\frac{5}{2x\\sqrt{5(\\ln x+1)}}.
$$

Эта производная положительна и убывает на $[2,4]$, поэтому

$$
q=\\max_{x\\in[2,4]}|\\varphi'(x)|=\\varphi'(2)\\approx0.429613<1.
$$

Функция $\\varphi$ возрастает и переводит $[2,4]$ в себя, так что метод сходится к единственному корню на выбранном отрезке.

**Точность и остановка**

В пособии дана апостериорная оценка для найденного приближения:

$$
|x_{k+1}-x_*|\\leq\\frac{q}{1-q}|x_{k+1}-x_k|.
$$

В коде правая часть записана `q * difference / (1.0 - q)`. Как и для других скалярных методов, внутренний порог `eps / 2` оставляет запас на округление печатаемого ответа. Нулевая строка таблицы — исходное $x_0=3$, для неё выводится оценка по невязке $|f(x_0)|/0.3$. Каждая следующая строка содержит номер шага, корень, невязку и оценку ошибки.

**Ответ:** $x\\approx3.31559798$.

## 6. Метод Ньютона для системы

**Дано**

$$
\begin{cases}
F_1(x,y)=x^2+y-5=0,\\
F_2(x,y)=x+y^2-3=0,
\end{cases}
\qquad (x_0,y_0)=(1.5,0.5).
$$

**Решение**

Матрица Якоби содержит частные производные

$$
J(x,y)=\begin{pmatrix}2x&1\\1&2y\end{pmatrix}.
$$

При малой поправке $\Delta$ имеем $F(z+\Delta)\approx F(z)+J(z)\Delta$, где $z=(x,y)$. Приравнивая линейное приближение к нулю, получаем СЛАУ

$$
J(z)\Delta=-F(z).
$$

В начальной точке $F=(-2.25,-1.25)$, поэтому

$$
\begin{pmatrix}3&1\\1&1\end{pmatrix}
\begin{pmatrix}\Delta x\\\Delta y\end{pmatrix}
=
\begin{pmatrix}2.25\\1.25\end{pmatrix}.
$$

Из этой системы $\Delta x=0.5$, $\Delta y=0.75$. Новая точка

$$
(x_1,y_1)=(1.5+0.5,\ 0.5+0.75)=(2,1.25).
$$

В `newton_system()` поправки вычисляются по формулам Крамера для системы 2×2

```python
determinant = j11 * j22 - j12 * j21
delta_x = (-first * j22 + j12 * second) / determinant
delta_y = (j21 * first - j11 * second) / determinant
x = x + delta_x
y = y + delta_y
```

`first` и `second` — текущие значения $F_1,F_2$. `j11`, `j12`, `j21`, `j22` — элементы Якоби. Обе поправки вычисляются в одной старой точке, затем обновляются обе координаты. Новая матрица Якоби строится на следующей итерации.

Для варианта 11

$$
J(x,y)=
\begin{pmatrix}
-\cos(-x+\pi/2+2)&1\\
-1&\sin(-y+\pi/2-0.5)
\end{pmatrix}.
$$

Остановка проверяется по $\max(|F_1|,|F_2|)$. Слишком малый определитель вызывает ошибку. Порог $10^{-14}$ — проверка реализации, а не доказательство точной вырожденности. Для гладкой системы с невырожденным Якоби в корне метод локально сходится при достаточно близкой начальной точке. Ненулевой определитель в начальной точке сам по себе не доказывает сходимость.

### Проверка сходимости из выбранной точки $(-1,0)$

Дополнительное обоснование для защиты (не отдельный метод из учебника). Используем бесконечную норму $\|(u,v)\|_\infty=\max(|u|,|v|)$ и обозначаем поправку Ньютона $d_k=z_{k+1}-z_k$, $z_k=(x_k,y_k)$.

1. Вычисляем первые три шага теми же формулами Крамера, что и в программе:

| k | x | y |
| ---: | ---: | ---: |
| 0 | -1 | 0 |
| 1 | 0.19965506 | 0.82069716 |
| 2 | -0.10459287 | 0.52380527 |
| 3 | -0.13851799 | 0.53801088 |

Определители в первых двух точках ненулевые. Из чисел с запасом получаем $z_2\in[-0.105,-0.104]\times[0.523,0.525]$ и $\|d_2\|_\infty<0.04$. Округлённые значения в таблице только для чтения; запас в неравенствах существенно превышает округление. Проверка в `check_convergence.py` использует неокруглённые значения.

2. Возьмём прямоугольник $D=[-0.3,0.1]\times[0.3,0.8]$. В нём

$$
J=\begin{pmatrix}a&1\\-1&b\end{pmatrix},\qquad a=\sin(2-x),\ b=\cos(y+0.5).
$$

Здесь $0<a\le1$, $0<b\le1$ (аргументы лежат в $(0,\pi)$ и $(0,\pi/2)$ соответственно), поэтому $\det J=1+ab\ge1$. Обратная матрица:

$$
J^{-1}=\frac{1}{1+ab}\begin{pmatrix}b&-1\\1&a\end{pmatrix},\qquad \|J^{-1}\|_\infty\le2.
$$

3. У $F_1=\cos(2-x)+y$ вторая производная по $x$ ограничена единицей по модулю, остальные вторые производные нулевые. Аналогично у $F_2=\sin(y+0.5)-x-1$ ненулевая вторая производная только по $y$, и её модуль не больше единицы. По формуле Тейлора и равенству $J(z_k)d_k=-F(z_k)$

$$
\|F(z_{k+1})\|_\infty\le\tfrac12\|d_k\|_\infty^2.
$$

Следовательно, пока точки находятся в D,

$$
\|d_{k+1}\|_\infty=\|J(z_{k+1})^{-1}F(z_{k+1})\|_\infty\le\|d_k\|_\infty^2.
$$

4. Начальная для этой оценки поправка $\|d_2\|_\infty<0.04$. Следующие поправки не превосходят $0.04^2$, $0.04^4$ и т. д. Их сумма вместе с первой не превосходит геометрического ряда $0.04/(1-0.04)<0.042$. Расстояние от $z_2$ до ближайшей границы D больше 0.19. Поэтому по индукции все последующие точки остаются в D, где оценка обратной матрицы действительна. Сумма поправок конечна, последовательность сходится. Невязка стремится к нулю по оценке Тейлора, значит предел является решением системы.

Итак, доказано, что именно выбранная начальная точка после двух корректных шагов попадает в область гарантированной сходимости. Это не утверждение о сходимости из любой точки. Обычный алгоритм Ньютона в `src/system_methods.py` и `raw/task06_newton_system.py` не меняется; дополнительный скрипт проверяет численные предпосылки доказательства. Запуск: `python check_convergence.py`. Численная проверка не является интервальной сертификацией машинных округлений.

**Ответ для учебного примера** $(x,y)\approx(2,1)$. Подстановка даёт $4+1-5=0$ и $2+1-3=0$.

## 7. Метод спуска

**Дано**

Используется система и начальная точка из предыдущего примера.

**Решение**

Составляем сумму квадратов левых частей

$$
\Psi(x,y)=F_1(x,y)^2+F_2(x,y)^2.
$$

Её градиент содержит две частные производные

$$
\Psi_x=2(F_1F_{1x}+F_2F_{2x}),\qquad
\Psi_y=2(F_1F_{1y}+F_2F_{2y}).
$$

Градиент задаёт направление наиболее быстрого локального роста. Для уменьшения функции используется антиградиент

$$
x_{k+1}=x_k-\alpha\Psi_x,\qquad
y_{k+1}=y_k-\alpha\Psi_y.
$$

$\alpha$ — множитель при направлении спуска. В программе он начинается с `0.25` на каждой итерации. Если новая сумма квадратов не уменьшилась, шаг делится пополам. Это схема дробления шага из § 3.7. Точный минимум вдоль направления здесь не ищется.

Для учебной системы в точке $(1.5,0.5)$

$$
F_1=-2.25,\quad F_2=-1.25,\quad
\Psi=6.625,\quad \nabla\Psi=(-16,-7).
$$

Проверяем пробные шаги

| $\alpha$ | Пробная точка | Новая $\Psi$ | Решение |
| ---: | --- | ---: | --- |
| 0.25 | $(5.5,2.25)$ | 813.44140625 | Уменьшить шаг |
| 0.125 | $(3.5,1.375)$ | 80.10571289 | Уменьшить шаг |
| 0.0625 | $(2.5,0.9375)$ | 4.92872620 | Принять точку |

Фрагмент `gradient_descent()`

```python
step = DESCENT_STEP
while True:
    next_x = x - step * grad_x
    next_y = y - step * grad_y
    next_first, next_second = system_values(next_x, next_y)
    next_psi = next_first * next_first + next_second * next_second
    if next_psi < psi:
        break
    step = step / 2.0
    if step < 1e-14:
        raise RuntimeError("Не удалось уменьшить сумму квадратов невязок")

x = next_x
y = next_y
```

При подборе шага `x`, `y` и градиент сохраняются. Меняется только `step`. Координаты обновляются после принятия точки. На следующей итерации функции и градиент вычисляются заново.

Остановка по малому градиенту не считается решением системы. Требуется малая невязка $\max(|F_1|,|F_2|)$. Если градиент равен нулю при ненулевой невязке либо подходящий шаг не найден, программа сообщает об ошибке. Для выбранной начальной точки варианта 11 метод сошёлся; произвольный старт может привести к другому поведению.

**Ответ для учебного примера** $(x,y)\approx(2,1)$, $\Psi\approx0$.

## 8. Сравнение результатов и точности

**Дано**

Уравнение и система варианта 11. `eps = 1e-8`. Во всех методах используется половина этого допуска как внутренний порог остановки.

**Решение**

Для скалярного уравнения невязка равна $|f(x)|$, погрешность аргумента — $|x-x_*|$. Точное $x_*$ для вычисления невязки не требуется. Код выводит оценки погрешности аргумента по следующим формулам

| Метод | Оценка в столбце «Оценка ошибки x» |
| --- | --- |
| Половинное деление | Половина длины текущего отрезка |
| Ньютон, хорды | $|f(x)|/0.3$ |
| Комбинированный | Половина длины текущего отрезка |
| Простые итерации | $q|x_k-x_{k-1}|/(1-q)$, кроме начальной строки |

Для системы выводятся $F_1$, $F_2$, максимальная невязка и сумма квадратов $\Psi$. Оценка погрешности координат по одной невязке в этой работе не заявляется. Задание 8 допускает проверку невязкой.

Результаты контрольного запуска

| Метод | Итераций | Ответ | Невязка |
| --- | ---: | --- | ---: |
| Половинное деление | 28 | $x\approx3.31559798$ | $3.070\cdot10^{-9}$ |
| Ньютон | 4 | $x\approx3.31559798$ | $7.727\cdot10^{-14}$ |
| Секущие с фиксированным концом | 11 | $x\approx3.31559798$ | $7.558\cdot10^{-10}$ |
| Комбинированный | 4 | $x\approx3.31559798$ | $1.017\cdot10^{-13}$ |
| Простые итерации | 13 | $x\approx3.31559798$ | $1.524e-09$ |
| Ньютон для системы | 5 | $(-0.13868462,\ 0.53785300)$ | $3.331\cdot10^{-16}$ |
| Спуск | 22 | $(-0.13868462,\ 0.53785300)$ | $4.717\cdot10^{-9}$ |

Невязки в таблице относятся к внутренним значениям до округления ответа. Последние машинные разряды могут отличаться на другой платформе. Оценки получены из математических формул; интервального учёта всех машинных округлений в программе нет.

Число итераций сравнивается при указанных начальных данных и критериях остановки. Стоимость одной итерации различается: Ньютону нужна производная, а комбинированный метод обновляет сразу две границы. Число итераций само по себе не является измерением времени работы.

В конце программа также выводит разброс ответов скалярных методов и различие двух решений системы. Эти величины характеризуют согласованность методов, но не заменяют оценку погрешности относительно точного решения.

**Ответ**

$$
x\approx3.31559798
$$

для уравнения на $[2,4]$ и

$$
(x,y)\approx(-0.13868462,\ 0.53785300)
$$

для системы.
