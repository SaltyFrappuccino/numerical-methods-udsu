# Лабораторная работа №3 — метод наименьших квадратов

**Задание №8, вариант 11.** Тема: теория приближения и аппроксимация функций.

Основа: А. С. Банников, И. Г. Ким, Н. В. Латыпова. *Численные методы. Часть 1*. УдГУ, 2018, § 4.5, формулы (36)–(37), и § 6.3, задание №8.

## Задача

По семи заданным точкам построить прямую линейной регрессии методом наименьших квадратов:

| x | 0 | 1 | 2 | 3 | 4 | 5 | 6 |
|---|---:|---:|---:|---:|---:|---:|---:|
| y | −3.31 | −3.53 | −3.25 | −3.19 | −3.11 | −3.24 | −3.38 |

Ищем многочлен первой степени:

\[
Q_1(x) = a_0 + a_1x.
\]

В отличие от интерполяции, не требуем точного прохождения прямой через все точки. Подбираем коэффициенты так, чтобы сумма квадратов отклонений была наименьшей:

\[
S = \sum_{i=0}^{6}(Q_1(x_i)-y_i)^2 \longrightarrow \min.
\]

## Математическое решение

В § 4.5 учебника для многочлена первой степени используются суммы:

\[
S_0 = 7,\qquad S_1=\sum x_i = 21,\qquad S_2 = \sum x_i^2 = 91,
\]

\[
t_0 = \sum y_i = -23.01,\qquad t_1 = \sum x_i y_i = -68.52.
\]

По условию минимума \(\partial S/\partial a_0=0\) и \(\partial S/\partial a_1=0\) получается нормальная система (37):

\[
\begin{cases}
S_0a_0 + S_1a_1 = t_0,\\
S_1a_0 + S_2a_1 = t_1.
\end{cases}
\]

Для нашего варианта:

\[
\begin{cases}
7a_0+21a_1=-23.01,\\
21a_0+91a_1=-68.52.
\end{cases}
\]

Вычитаем из второго уравнения первое, умноженное на \(21/7=3\):

\[
28a_1 = 0.51, \qquad a_1 = 0.018214285714\ldots
\]

Возвращаемся к первому уравнению:

\[
a_0=\frac{-23.01-21a_1}{7}=-3.341785714285\ldots
\]

**Итоговая прямая:**

\[
\boxed{Q_1(x)\approx -3.341785714 + 0.018214286x}
\]

Сумма квадратов отклонений для этой прямой:

\[
\boxed{S\approx0.103253571.}
\]

## Как код соответствует формулам

- `src/data.py`: исходные табличные точки.
- `src/least_squares.py`: вычисление `S0`, `S1`, `S2`, `t0`, `t1`; исключение `a0` из двух уравнений; вычисление `a1` и `a0`; значение прямой и сумма квадратов отклонений.
- `src/main.py`: вывод нормальной системы, результатов, отклонений по каждой точке и проверка подстановкой коэффициентов в оба уравнения.
- `run.py`: запуск программы.

Вычисление `a1` в `fit_line` соответствует вычитанию уравнений:

```python
factor = S1 / S0
left = S2 - factor * S1
right = t1 - factor * t0
a1 = right / left
a0 = (t0 - S1 * a1) / S0
```

Здесь `factor` равен 3, `left` равен 28, `right` равен 0.51.
